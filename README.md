
# MapWriter

Инструмент для быстрой отрисовки фигур, и тактических обозначений с помощью мыши. Использовался в связке с редактором карт, чтобы аккуратно размечать области, рисовать схемы, красиво оформлять графику поверх рабочей области.

## Что умеет

- Рисование геометрических фигур, линий и выделений на основе движений мыши.
- Расстановка меток и работа с тактической доской поверх карты.
- Нарезка и подготовка иконок и шаблонов для быстрого добавления на схему.
- Выбор цветовых пресетов для визуального разделения зон и объектов.

## Структура файлов

- `main.py` - точка входа и запуск основного окна отрисовки.
- `tactical_constructor.py` - инструменты создания фигур и управления элементами на холсте.
- `tactical_board.py` - логика отображения сетки, слоев и нанесенных объектов.
- `cutter.py` - утилита для нарезки исходных изображений на отдельные иконки и шаблоны.
- `radar_ui.py` - элементы интерфейса и панель управления отрисовкой.
- `radar_mem.py` - вспомогательный модуль работы с координатами и состоянием.

## Установка и запуск

Клонируйте репозиторий и активируйте виртуальное окружение
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
Установите недостающие библиотеки
  ```
  pip install opencv-python pillow numpy
  ```

Запустите приложение
  ```
  python main.py
  ```
